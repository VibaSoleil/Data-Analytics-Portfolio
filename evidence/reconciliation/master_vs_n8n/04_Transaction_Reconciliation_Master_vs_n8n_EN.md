1.4 Reconciliation Approach

The audit is conducted using a source-to-report reconciliation approach.

The validation stages include:

Examination of the dataset structure.

This approach ensures that every value appearing in the n8n report can be traced back to the source transaction data.

1.5 Reconciliation Principles

The TRANSACTION audit is conducted based on the following principles.

Data Integrity

All transactions originating from the source data must remain intact throughout the transformation process.

Accuracy

All transaction KPIs must produce the same values as the calculations in the TRANSACTION MASTER.

Consistency

The transformation results must be consistent with the structure and values of the source data.

Traceability

All analysis results must be traceable back to the source transactions and the transformation logic used.

Auditability

All evidence, validation results, investigation processes, and audit conclusions must be properly documented so that they can be accounted for in subsequent audit processes.
