# INTRODUCTION

## 1.1 Background

This document is prepared as part of the validation and reconciliation process between the financial analysis process based on Manual Python and the financial analysis process based on the n8n workflow automation within the Data Analyst project.

Financial Analysis is one of the main modules in the analytics pipeline, intended to generate business information related to:

Total company revenue.
Average transaction value.
Monthly revenue growth.
Revenue contribution by product.
Pareto 80/20 analysis.
Business insights related to financial performance.

The reconciliation process is performed to ensure that the analysis results generated by the n8n workflow are consistent with the results of the Manual Python analysis as the primary baseline.

## 1.2 Reconciliation Objectives

The main objectives of the Financial Analysis reconciliation process are:

### 1. KPI Consistency Validation

To ensure that the Key Performance Indicator (KPI) values between Manual Python and n8n produce the same values.

The validated parameters include:

Total Revenue.
Average Transaction Value.
Monthly Revenue.
Product Revenue Contribution.
Pareto Contribution.

### 2. Data Structure Validation

To ensure that:

The input dataset used is the same.
The data volume is consistent.
The column structure remains unchanged.
The transformation process produces consistent data.

### 3. Business Logic Validation

To ensure that all business calculations in n8n follow the same analytical logic as Manual Python, including:

Revenue calculation.
Grouping by month.
Product ranking based on revenue.
Revenue contribution calculation.
Pareto analysis.

### 4. Supporting Audit and Documentation

This document serves as technical evidence that the Financial Analysis pipeline:

Can be reproduced.
Can be traced.
Produces consistent output.
Is ready to be used in the Data Analyst project report.
