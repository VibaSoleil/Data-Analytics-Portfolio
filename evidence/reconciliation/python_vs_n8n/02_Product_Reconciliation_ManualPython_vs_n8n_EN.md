# 4. Source Code Verification

Investigation of the source code shows that the two artifacts have different functions but produce the same KPIs.

## ManualPython

Source:

```text
SCRIPT/
ODC_Bag8_FinalReport_03_PRODUCT_Professional.py
```

This script performs transaction data aggregation by product to produce a Product Summary report containing:

* Product Revenue
* Product Ranking

The resulting output is a summary of the sales performance of each product.

---

## n8n Pipeline

Source:

```text
SCRIPT/
ODC_Bag8_FinalReport_03_PRODUCT_Professional_n8n.py
```

The n8n Pipeline produces a cleaned transaction dataset (**Company_Data_Cleaned_n8n.csv**).

The dataset is then used as the basis for recalculating all Product KPIs so that the results can be independently compared against the ManualPython report.

Thus:

* **ManualPython** functions as an analytical report.
* **n8n Pipeline** functions as an automation process that produces a transaction dataset for KPI recalculation.

---

# 5. Reconciliation Methodology

Because the two artifacts have different data structures, the reconciliation is not performed through direct file comparison.

The method used is as follows:

1. Read the ManualPython Product Report.

2. Read the dataset produced by the **Company_Data_Cleaned_n8n.csv** pipeline.

3. Aggregate the data based on:

   * id_produk
   * nama_produk

4. Recalculate the following KPIs:

   * Product Revenue
   * Product Ranking
   * Product Count

5. Compare the recalculated results against the ManualPython Product Report.

6. Verify that all KPIs have identical values.

This method ensures that all Product KPIs in the ManualPython report can be independently reproduced from the dataset produced by the n8n automation pipeline.
